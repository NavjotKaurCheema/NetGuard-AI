Download: https://www.unb.ca/cic/datasets/ids-2017.html  |  Also available on Kaggle

Generation Tool: CICFlowMeter — extracts 78 statistical features from raw pcap network captures, including packet-level statistics, flow-level timing, and TCP flag counts.

Why this dataset: CICIDS2017 is the most widely cited IDS benchmark in recent literature (Rajathi & Rukmani 2025; Sakib & Tabassum 2025; Ramesh IJIRT 2024). It contains realistic, diverse attack traffic captured from actual network hardware with 25 users, making it representative of real-world network environments.

Preprocessing Pipeline
1

Duplicate Row Removal

Identical rows (same values across all 78 features) were removed. Duplicates inflate metrics artificially and cause overfitting — the model memorises repeated rows rather than learning patterns.

2,830,743 → 2,522,362 rows  |  Removed: 308,381 duplicates (10.89%)
2

Infinite Value Replacement

Flow Bytes/s and Flow Packets/s can produce ±∞ when flow duration is 0 (single-packet flows). All ±Inf values were replaced with NaN for subsequent imputation. Machine learning models cannot process infinite values.

All ±Inf replaced with NaN before imputation step
3

Missing Value Imputation

After Inf replacement, 3,128 NaN values remained. These were imputed with the column median (more robust than mean for skewed distributions). Rows with missing labels were dropped.

3,128 values imputed with per-column median
4

Skewness Correction (log1p transform)

Network traffic features are heavily right-skewed — a few large flows dominate. Features with skewness > 3.0 and non-negative values were transformed using log1p(x) = ln(1+x). This compresses the range, improving gradient-based model convergence. (Sakib & Tabassum 2025)

40 of 78 features corrected  |  e.g. Total Fwd Packets, Flow Duration, Total Length of Fwd Packets
5

Feature Standardisation (StandardScaler)

All selected features scaled to zero mean and unit variance. Critical for Isolation Forest (geometry-based) and deep learning models. Fitted only on training data — applied to test data using training statistics to prevent data leakage.

Each feature: mean=0, std=1  |  Scaler fitted on train set only

Feature Selection Methodology
From 78 available features, a four-stage research-backed pipeline was applied to select the 30 most discriminative features. Method follows Hossain et al. (cited in Rajathi & Rukmani 2025) who proposed correlation analysis + mutual information for IDS feature selection, and Ramesh IJIRT (2024) who used Random Forest importance on CICIDS2017.
S1

Near-Constant Feature Removal (Variance Filter)

Features with standard deviation < 0.01 across all rows carry no discriminative information. Removed 10 features including all bulk-rate features (Fwd/Bwd Avg Bytes/Bulk, etc.) which are zero for virtually all flows.

78 → 68 features  |  Removed: Bwd PSH Flags, Fwd/Bwd URG Flags, CWE Flag Count, all Bulk Rate features
S2

Pearson Correlation Filter (r > 0.95)

Highly correlated feature pairs are redundant — they encode the same information. For each correlated pair, the lower-importance feature was removed. Notable redundancies: Avg Fwd Segment Size ≈ Fwd Packet Length Mean (identical formula), Subflow Fwd Packets = Total Fwd Packets, Packet Length Variance = Std².

68 → 46 features  |  Removed 22 redundant features
S3

Random Forest Gini Importance Ranking

A 150-tree Random Forest was trained on a 150,000-row stratified sample. Gini importance measures how much each feature reduces class impurity across all trees. Top 35 features by importance were retained as candidates.

Top feature: Bwd Packet Length Std (0.121)  |  Selected top 35 candidates
S4

Mutual Information Cross-Validation

Mutual Information (MI) measures non-linear statistical dependency between each feature and the label — it captures relationships that Pearson correlation misses. Features confirmed by BOTH RF Gini AND MI rankings form the final set. This dual-method validation ensures robustness.

Final: 30 features confirmed by both methods  |  All 30 appear in both Top-35 RF and Top-35 MI lists
Result: 30 research-validated features selected from 78. This represents a 61.5% reduction in feature space while retaining maximum discriminative power — improving model generalisation and reducing inference time.

Stratified Split: sklearn's train_test_split(stratify=y) ensures both training and test sets maintain the same 83:17 benign:attack ratio as the full dataset. Without stratification, a random split could accidentally put most attacks in one partition, leading to misleading evaluation metrics.

Data Leakage Prevention: The StandardScaler is fitted only on training data and then applied to the test set using training statistics. This prevents any test-set information from influencing preprocessing — a common source of artificially inflated metrics in published IDS papers.

Evaluation: All metrics (Accuracy, Precision, Recall, F1, AUC-ROC, FAR) are computed exclusively on the 504,473-sample test set. The model has never seen these samples during training.
