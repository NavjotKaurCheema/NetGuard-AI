Key Features

Hybrid ML Detection

Combines XGBoost (supervised) for known attacks and Isolation Forest (unsupervised) for zero-day anomalies.

GeoIP Visualisation

Each flow is geolocated and plotted live on a Leaflet world map — green for benign, red for attacks.

Explainable AI (SHAP)

SHAP values tell you exactly which network features caused an alert — transparency for analysts.

Live Dashboard

Real-time alert feed, attack frequency chart, ROC curve, confusion matrix — all in one dashboard.

Dynamic Tuning

Adjust alpha, beta, and threshold sliders live without restarting the server.

Persistent Logging

All predictions are stored in SQLite for historical analysis and performance tracking.

Why Network Security?

🛡️ Preventing Breaches

Malicious actors continuously probe networks for vulnerabilities, aiming to steal data, disrupt services, or gain unauthorized access.

🔒 Data Protection

Sensitive corporate and user data must be protected from exfiltration and unauthorized access during transit.

✅ Ensuring Trust

A secure network is fundamental to operational integrity. Attacks can erode customer trust and lead to significant financial damage.

Tools & Tech Stack

Flask

REST API & template server powering the demo.

Socket.IO

Real-time communication between replay generator and dashboard.

Pandas

Data preparation, aggregation, and CSV replay utilities.

scikit-learn

Machine learning models (XGBoost, IsolationForest) used for detection.

SHAP

Explainability — shows which features triggered an alert.

GeoLite2-City.mmdb

GeoIP database used to map IP addresses to geographic locations, enabling visualization of attack origins in real time.

SQLite

Lightweight database for persistent prediction logging.
